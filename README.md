# 🏡 Far & Fair — Smart Accommodation & Upfront Budget Planner

**Far & Fair** solves a major pain point for students, interns, working professionals, and budget travellers: **hidden upfront costs**. While standard booking platforms only show daily rent, Far & Fair calculates the true total cost of living alongside the **exact cash required upfront** (first stay + 100% refundable security deposits), ensuring users never face unexpected financial surprises.

## ✨ Key Features
* **Smart Budget Dashboard:** Dynamically calculates actual trip spending (rent + estimated homestyle meals + local public transport) plus refundable security deposits.
* **Advanced Multi-Filter Search:** Filter properties by destination, check-in dates, duration, max daily rent, sharing occupancy (1 to 3+ sharing), and must-have facilities (**Food Included**, **Wi-Fi**, **Gym**, **Laundry**, **24/7 Security**, and **Study Room**).
* **Side-by-Side Comparison:** Shortlist up to 3 stays to evaluate daily rates, deposits, and upfront totals in a comparative view.
* **Interactive Maps & Local Attractions:** Integrated Leaflet.js & OpenStreetMap view marking the exact accommodation alongside nearby transit hubs and sightseeing spots.

## 🛠️ Tech Stack & Architecture
* **Frontend:** HTML5, CSS3 (Modern Flexbox/Grid), Vanilla JavaScript 
* **Backend:** Python Flask & RESTful API endpoints, custom filter & budget logic
* **Database:** Python SQLite3 with automatic lightweight seeding for 10+ sample properties across Bengaluru, Mumbai, and Delhi
